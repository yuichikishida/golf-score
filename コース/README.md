# コースデータ

ラウンド前に、回るコースのデータをこの書式のJSONで用意し、アプリの「コース管理」から取り込む。
一度取り込めば端末に残るので、同じコースの2回目以降は不要。

## 作り方

Claude(このリポジトリで作業しているセッション)に

> 〇〇カントリークラブ(東→西)のスコアカードをJSONにして

と頼む。Claudeが調べて下書きを作るので、**必ずコース公式サイトのコースガイドと突き合わせて確認する**。
Webの情報は古かったり、コース改修前のヤーデージだったりする。

一番確実なのは、**スコアカードやコースガイドの写真をClaudeに送ってJSON化してもらう**方法。
これなら誤りが入らない。

アプリの「手入力で新規作成」から直接打ち込むこともできる(18ホールで5分程度)。

## 書式

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `name` | ○ | コース名。27ホール以上のコースは回る組み合わせまで含める(例: `〇〇CC(東→西)`) |
| `location` | | 所在地 |
| `note` | | 出典や注意書き |
| `tees` | | ティー名の配列。省略時は `["レギュラー"]` |
| `holes[].no` | ○ | ホール番号(1始まり) |
| `holes[].par` | ○ | パー |
| `holes[].hdcp` | | ハンディキャップ順位(1が最難)。**分析でかなり効くので入れておきたい** |
| `holes[].yards` | | ティー名をキーにしたヤーデージ |

`hdcp` と `yards` は無くてもアプリは動く。ただし「難しいホールで崩れているのか、
簡単なホールを取りこぼしているのか」の分析ができなくなる。
