# ゴルフスコア

ラウンド中はスコアを入れるだけ。分析はあとからAIにやらせる、という割り切りのWebアプリ。

## 考え方

市販のゴルフアプリは、GPS・距離計測・コースDB・分析を全部アプリの中でやろうとして、
その結果としてバッテリーを食い、月額課金になり、それでいて分析は浅い。

このアプリは逆に振り切っている。

```
[ラウンド中]              [保存]                    [あとで]
スマホのWebアプリ          Googleドライブ            Claudeに投げる
スコア/パット/FW/OB  ──→   JSON + Markdown    ──→   深い分析・練習メニュー
(3タップ/ホール)          (端末内にも残る)
```

- **アプリは入力に徹する。** 分析ロジックもAPIキーも持たない。だから壊れないし、無料で、電池も食わない
- **知能は後段に置く。** 分析の質はClaude側でいくらでも上げられる。アプリを更新する必要がない
- **データは自分の手元にある。** 端末内(localStorage)とGoogleドライブ。サービスが終わっても消えない

## 使い方

### 1. ラウンド前:コースを登録する

Claudeに「〇〇カントリークラブのスコアカードをJSONにして」と頼むか、
スコアカードの写真を送ってJSON化してもらう。それをアプリの「コース管理」で貼り付ける。
一度入れれば端末に残るので、同じコースの2回目以降は不要。

書式は [`コース/README.md`](コース/README.md) を参照。手入力でも作れる(18ホールで5分程度)。

### 2. ラウンド中:1ホールにつき3タップ

打数 → パット数 → ティーショット(キープ/左/右)。OBと罰打があればカウンターを押す。
スクロール無しで完結する。オフラインでも動く。

### 3. ラウンド後:保存してClaudeに渡す

「Googleドライブに保存」で JSON と Markdown が書き出される。

- **PCのChrome/Edge**: 事前に保存先フォルダを選んでおけば、ドライブの同期フォルダへ直接書き込まれる
- **iPhone**: 共有シートが開くので Googleドライブ を選ぶ
- どちらも使えない場合はダウンロードされる

そのファイルをClaudeに渡すか、「分析プロンプトをコピー」で全部入りのプロンプトを貼り付ける。
何を分析させるかは [`分析プロンプト.md`](分析プロンプト.md) にまとめてある。

## 記録している項目

ホールごとに **打数・パット数・ティーショットの方向・OB・その他の罰打・メモ**。
この5項目だけで、次のものが出せる。

| 指標 | 意味 |
| --- | --- |
| パーオン率 (GIR) | `打数 − パット数 ≦ パー − 2` で判定 |
| フェアウェイキープ率 | パー4以上のみ。左右どちらに外したかも残る |
| スクランブリング率 | パーオンを外したホールでパー以上で上がれた率 |
| 平均パット / 3パット数 | パーオンしたホールの平均パットも別に出す |
| 罰打の合計 | OBとその他を分けて記録 |
| スコア分布 | バーディ以上 / パー / ボギー / ダボ以上 |

HDCP順位とヤーデージをコースデータに入れておくと、
「難しいホールで崩れているのか、簡単なホールを取りこぼしているのか」まで分析できる。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体。HTML/CSS/JSを1ファイルに収めている。ビルド工程なし |
| `sw.js` | Service Worker。一度読み込めば圏外でも動くようにする(ゴルフ場は電波が悪い) |
| `manifest.webmanifest` / `icon.svg` | ホーム画面に追加してアプリのように使うための定義 |
| `コース/` | コースデータのJSONと、その書式の説明 |
| `分析プロンプト.md` | Claudeに投げる分析プロンプトの原文 |
| `要件定義.md` | なぜこの設計にしたかの記録 |

## デプロイ

GitHub Pages(mainブランチ、root)。mainにプッシュすれば数分で反映される。

iPhoneでは Safari で開いて「共有 → ホーム画面に追加」しておくと、
アドレスバーの無い全画面で起動し、オフラインでも動く。
